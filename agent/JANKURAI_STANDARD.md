# Jankurai Adapter Standard

JMCP Talk owns speech runtime adapters, deterministic speech fixtures, local
ASR/TTS sidecars, and opt-in MiniCPM-o 4.5 live validation. It does not own
durable approvals, tool policy, ledgers, or turn state.

Default CI is deterministic and local. MiniCPM-o 4.5 live inference is only a
self-hosted GPU dispatch lane and a promotion receipt.
